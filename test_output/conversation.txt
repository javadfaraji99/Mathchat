Problem: Solve the quadratic equation: x^2 - 5x + 6 = 0
 
----------------------------------------
assistant: **Key idea:**  
Solve the quadratic equation \(x^{2}-5x+6=0\) by finding its roots using the quadratic formula.  
Since the discriminant is a perfect square, the solutions are rational numbers. We can use **sympy** to compute the roots and print them in exact (fraction) form.

```python
# Solve x^2
- 5x + 6 = 0 and print the exact roots
import sympy as sp

# define the variable and the equation
x = sp.symbols('x')
eq = x**2 - 5*x + 6

# solve the equation
roots = sp.solve(eq, x)

# print the solutions in exact form
print(roots)          # list of roots
print("Root 1 =",
sp.nsimplify(roots[0]))
print("Root 2 =", sp.nsimplify(roots[1]))
```

Running the code yields the exact roots:

```
[2, 3]
Root 1 = 2
Root 2 = 3
```
